# 🍄 ГРИБНИК — симулятор тихой охоты

3D-игра про сбор грибов в русском лесу. Браузерная, на Three.js, **без сборки и без зависимостей** — положил файлы на GitHub Pages и играешь по ссылке.

Один забег — это один день, 12 минут. Собираешь быстро — растёт множитель. Набил тару — несёшь в приёмный пункт, там дают тару побольше. А ещё в лесу живут медведь, кабан, волки и хариус.

---

## Как запустить

### Локально

Нужен любой статический сервер (просто открыть `index.html` двойным кликом нельзя — ES-модули требуют `http://`):

```bash
python -m http.server 8000
```

Дальше открой <http://localhost:8000>.

### На GitHub Pages

1. Создай репозиторий и залей туда содержимое этой папки.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту игра будет на `https://<твой-ник>.github.io/<репозиторий>/`.

Файл `.nojekyll` уже лежит в репозитории — он нужен, чтобы Pages не пытался обрабатывать папку `js/` как Jekyll-шаблоны.

## Управление

| Клавиша | Действие |
|---|---|
| **WASD** | идти |
| **Shift** | бежать (тратит силы) |
| **ЛКМ** | сорвать гриб · ударить ножом · выстрелить |
| **Пробел** | **рывок в сторону** — так уходят от зверя |
| **E** | сдать грибы в пункте · подобрать находку |
| **1 / 2** | нож / ТТ, **ПКМ** или колесо — переключить |
| **R** | перезарядка |
| **Esc** | пауза |

## Что внутри

**Мир.** Километр на километр, зациклен по обеим осям: ушёл за край — вышел с противоположного, шва не видно. Рельеф, озёра, сосняк, ельник, березняк и открытые поляны. Грибы растут там, где им положено: опята и вешенки — на пнях, шампиньоны и зонтики — на полянах, грузди и лисички — в сырых местах. День идёт от утра к закату, свет и туман меняются вместе с ним.

**21 вид грибов** средней полосы. Белый, подосиновик, подберёзовик, рыжик, лисичка, груздь, маслёнок, моховик, опёнок, вешенка, сыроежка, шампиньон, зонтик, дождевик — и отдельно редкий белый-исполин на 720 очков. Ядовитые (мухомор, бледная поганка, сатанинский, ложный опёнок, пантерный) сбрасывают серию, а поганка ещё и травит.

**Множители.** Каждый гриб, сорванный в течение 3,4 секунды после предыдущего, поднимает множитель — до ×5. Промедлил — серия сгорела.

**Тара растёт.** Плетёная корзина (14) → эмалированное ведро (30) → брезентовый рюкзак (60) → садовая тележка (120) → прицеп к «Буханке» (260). Апгрейд дают, когда приносишь в пункт почти полную тару. Каждая следующая тара — ещё и множитель к цене.

**Коррида.** Сорвал гигантский мухомор — выбежал медведь. Сатанинский гриб — кабан. Зверь ревёт, роет землю и идёт на таран. Пока он далеко — доворачивает за тобой, и ранний рывок не спасёт; траектория фиксируется метрах в шести. Вот тогда — **Пробел** в сторону, время притормаживает, зверь проносится мимо: **¡OLÉ!**, очки и прибавка к множителю. Медведь при попадании убивает сразу. Кабан снимает 58.

**Волки** ходят стаей со второй половины дня и кусают, обходя по дуге. **Хариус** выпрыгивает из воды и атакует прыжками. Да, рыба. Да, она бежит за тобой по лесу.

**Оружие.** Нож — с первой секунды. А ровно на отметке 3:00 в лесу кто-то стреляет и бросает ящик — там ТТ и 16 патронов. Дальше патроны ищешь по лесу, они видны на радаре. Медведя из ТТ валят четыре точных попадания, в голову — быстрее.

**Смерть** не обнуляет забег: половина несданного пропадает, сданное остаётся. Поэтому сдавать выгодно чаще, чем кажется.

## Доска рекордов

Из коробки доска локальная (`localStorage`) — игра работает сразу, но каждый видит только свои забеги. Ник задаётся на старте, пароля нет: под каким ником играешь, под таким и попадаешь в таблицу.

Чтобы рейтинг стал **общим для всех друзей**, заполни в [`js/config.js`](js/config.js) один из двух блоков. Что заполнено — то и работает.

### Вариант A: Firebase Realtime Database (проще, ключей не нужно)

1. [console.firebase.google.com](https://console.firebase.google.com) → **Create a project** → имя `gribnik` → Google Analytics можно выключить.
2. Слева **Build → Realtime Database** → **Create Database** → регион любой → стартовать в **Locked mode** (правила пропишем следующим шагом).
3. Вкладка **Rules** → заменить содержимое на файл [`firebase-rules.json`](firebase-rules.json) → **Publish**.
4. На вкладке **Data** скопировать адрес базы вида `https://gribnik-1234-default-rtdb.europe-west1.firebasedatabase.app` и вписать его в `FIREBASE.dbUrl`.

Ключи не нужны вообще: доступ целиком определяют правила из шага 3 — доску читают все, добавлять можно только новые записи, а править и удалять существующие нельзя (`".write": "!data.exists()"`). Поля проверяются по типам и длине, лишние поля отвергаются.

### Вариант B: Supabase

1. Новый проект на [supabase.com](https://supabase.com) (на бесплатном тарифе их не больше двух).
2. **SQL Editor → New query** → выполнить [`supabase-setup.sql`](supabase-setup.sql).
3. **Project Settings → API Keys**: скопировать Project URL и ключ `anon public` (подойдёт и новый `publishable`) в `SUPABASE`.

### Что общего

Результат уходит на сервер в конце каждого забега. Если сети нет — забег кладётся в очередь в браузере и досылается при следующем запуске, так что ничей рекорд не теряется. Если база недоступна, игра не виснет и не падает: под доской появляется «⚠ доска недоступна», и показываются локальные забеги.

Заводи под игру **отдельный проект**, а не тот, где лежат рабочие данные: ссылку на игру увидит много людей, а вместе с ней и адрес базы.

> Защиты от накрутки счёта нет: результат считает браузер, и при желании его можно подделать через консоль. Для игры с друзьями это нормально; для честного рейтинга счёт пришлось бы пересчитывать на сервере.

## Структура

```
index.html          разметка меню, HUD и экранов
styles.css          весь интерфейс
js/
  main.js           запуск, меню, настройки
  game.js           игровой цикл, режиссёр событий дня
  config.js         ВСЕ настройки баланса + ключи Supabase
  world.js          зацикленный мир, чанки, лес, свет, приёмные пункты
  mushrooms.js      виды грибов и их процедурные модели
  animals.js        медведь, кабан, волк, хариус + механика тарана
  player.js         передвижение, рывок, здоровье
  weapons.js        нож и ТТ, хитскан, отдача
  pickups.js        находки в лесу
  inventory.js      тара, множители, сдача
  ui.js             HUD, радар, доска рекордов
  leaderboard.js    localStorage + Supabase
  audio.js          весь звук синтезируется через WebAudio
  utils.js          математика мира, рельеф, зацикливание
  geo.js            склейка геометрий
```

Ни одного бинарного ассета: модели, звуки и текстуры генерируются кодом. Весь репозиторий — несколько сотен килобайт текста.

### Что крутить для баланса

Почти всё живёт в [`js/config.js`](js/config.js): длительность дня, плотность грибов и деревьев, скорость игрока, окно серии, цена уворота, вместимость тары. Характеристики зверей — в `KINDS` в [`js/animals.js`](js/animals.js): там же `lockDist` — расстояние, на котором зверь перестаёт доворачивать, то есть буквально ширина окна для уворота.

Если на слабом ПК тормозит — в меню есть режим «Слабый ПК» (меньше травы и радиус прорисовки).
